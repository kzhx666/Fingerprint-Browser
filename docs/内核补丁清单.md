# 内核补丁清单

共 **93 项**补丁，全部由 `kernel/apply_patches.py` 以锚点方式应用，幂等可重复执行。

```bash
python kernel/apply_patches.py C:\chromium\src          # 应用
python kernel/apply_patches.py C:\chromium\src --check  # 只校验
python kernel/test_patches.py                            # 自测
```
